# Gallery map images (2026)

Drop finished exports here using this name pattern:

```text
day-01.png
day-02.jpg
…
day-30.png
```

Supported extensions (tried in order by `assets/js/gallery.js`): `.jpg`, `.jpeg`, `.png`.

Day 11 uses `day-11-decibels.png` through the `image` field in `days-data.js`.

Interactive maps do **not** go here — use `2026/day-NN.html` and set `embed` in `assets/js/days-data.js` (see Day 4). Day 12 keeps the sheet on the card and links the time map with `page`.
